    Static_fromCopyQuaternion

    • _fromCopyQuaternion(
          quat: IQuaternion,
          type: FloatTypedArrayConstructor,
      ): ILogQuaternion

      Converts a regular quaternion to its logarithmic form.

      Uses the formula log(q) = (θ / sin(θ)) * (x, y, z) where θ = acos(w). When θ is 0 (identity rotation) the result is a zero log quaternion. When θ is close to π the logarithm is not representable and a zero log quaternion is returned instead of Infinity/NaN.

      Parameters

      • quat: IQuaternion

        The source quaternion to convert

      • type: FloatTypedArrayConstructor

        The typed array constructor to use

      Returns ILogQuaternion

      A new log quaternion representing the logarithm of the input quaternion

    Class ShaderParameterDebugger

    Inspector for the values Rhodonite uploads to WebGL2 shaders.

    It reports both the CPU-side value of a shader semantic and the location/value the shader reads from the data texture, plus the real uniform value when the shader uses one (for needUniformInDataTextureMode and sampler uniforms).

    The decoder reads the CPU-side GPUInstanceData buffers, which are the same bytes that are uploaded to the data texture. It does not read back the GPU texture.

## Where to start

- **Using the library:** the [README](../README.md), then the [API overview](./API_OVERVIEW.md) and the samples in
  `samples/test_e2e/` (each one is a small, runnable program).
- **Reading the engine code:** [PROJECT_INDEX.md](./PROJECT_INDEX.md) ("Where a frame goes"), then the
  [design notes](./design-notes/README.md) of the feature you are reading.
- **Changing the engine:** [DEVELOPER_WORKFLOW.md](./DEVELOPER_WORKFLOW.md) and [CLAUDE.md](../CLAUDE.md).

## Keeping these documents correct

The source code is the reference. When a change renames an API, changes a default or moves a file, update the
documents that mention it in the same pull request. Measurements in the design notes are dated snapshots: add a new
dated measurement rather than editing an old number.
